# Prida — Contexto inicial del proyecto (página web)

## Resumen
Página web de producto para **Prida Europa**. Prida Europa tiene hoy **cuatro líneas de negocio** (ver "Líneas de negocio de Prida Europa" más abajo), pero esta primera versión (release 1) de la web se enfoca únicamente en dos: frutas asépticas y frutas liofilizadas y atomizadas. No es una web corporativa multi-línea en esta fase — es una decisión de foco para el release 1, no el retrato completo del negocio.

## Motivación / contexto (no es contenido de la web)
- Prida asistirá a la feria presencial **Fruit Attraction 2026** (6, 7 y 8 de octubre de 2026).
- La feria es un evento físico, no contenido a mostrar en la web.
- La web debe estar lista para la feria: la idea es que los visitantes conozcan Prida allí, visiten después la web y la usen como referencia de los productos que vende Prida.

## Líneas de negocio de Prida Europa
Prida Europa evolucionó desde el negocio con el que nació hasta tener, hoy, **cuatro líneas de negocio**:

| # | Línea de negocio | ¿Entra en el release 1 de la web? |
|---|---|---|
| 1 | **Productos venezolanos** (importación — la línea original, con la que nació Prida) | No |
| 2 | **Frutas Asépticas** (partner: Alimentos SAS) | **Sí** |
| 3 | **Frutas Liofilizadas y Atomizadas** (partner: Biovks) | **Sí** |
| 4 | **Bebidas** | No |

Es una **evolución del negocio, no un reemplazo**: Prida Europa no dejó atrás los productos venezolanos para pasar a la fruta — sumó líneas nuevas (fruta, bebidas) sobre la línea con la que nació. Las cuatro coexisten como negocio real de Prida Europa hoy.

## Alcance de la web (fase actual — release 1)
- Release 1 cubre únicamente las **dos líneas de fruta**: **Frutas Asépticas** y **Frutas Liofilizadas y Atomizadas** — porque son las que Prida va a vender en Fruit Attraction 2026.
- Las otras dos líneas — **productos venezolanos** y **bebidas** — quedan **fuera del alcance de este release**, a propósito. Es una decisión de foco para esta primera versión de la web, **no una discontinuación de esas líneas de negocio**: siguen activas y podrían incorporarse a la web en un release futuro.

## Historia de la marca Prida y relación con Prida Import (EE.UU.)
- Prida **nació** como negocio de **importación de alimentos venezolanos**, para llevarlos a otros países (EE.UU., España/Europa) — es la línea de negocio #1 de la tabla de arriba.
- **Prida Import** (www.pridaimport.com, Miami) es la operación en EE.UU. de esa línea original: distribuidor mayorista de productos venezolanos de consumo masivo (snacks, conservas, bebidas, marcas como Alimentos Polar, Nestlé, etc.). Es la **empresa hermana** de Prida Europa dentro de la misma marca.
- **Prida Europa** (la web que se está construyendo ahora) **evolucionó** a partir de esa línea original: sumó las dos líneas de fruta (Frutas Asépticas, Frutas Liofilizadas y Atomizadas) y una línea de bebidas, hasta llegar a las cuatro líneas actuales. No es un pivote ni un reemplazo — las cuatro conviven como negocio de Prida Europa hoy; el release 1 de la web simplemente elige mostrar solo dos.
- **La identidad visual (logo, paleta) es la misma** en toda la marca Prida, para todas sus líneas. Por eso pridaimport.com es una referencia de línea gráfica/marca perfectamente válida para esta web — aunque su *contenido de producto* (golosinas, bebidas venezolanas) no deba usarse como referencia de contenido para el release 1, que es 100% de fruta.

## Referencia adicional
- **www.pridaimport.com** (Prida USA) — no es un proveedor de producto, es la **empresa hermana** de Prida Europa dentro de la misma marca. Se usa como referencia de línea gráfica (logo, colores), no de contenido de producto para este release — ver aclaración arriba sobre el alcance de release 1 vs. el negocio completo de Prida.
